- [x] Phase 1, step 7 — Added `JWT_SECRET` (random 96-hex-char value) to `.env`/`.env.example`. Added `getUserByEmail()` to [userRepository.ts](src/repositories/userRepository.ts). Added `POST /auth/login` to [auth.ts](src/routes/auth.ts): validates `{ email, password }` via zod, looks up the user, compares the password with `bcrypt.compare`, and on success signs a JWT (`jsonwebtoken`, payload `{ sub, email }`, 1h expiry) with `JWT_SECRET`. On failure (unknown email or wrong password) both return an identical generic `401 "Invalid email or password."` — and `bcrypt.compare` always runs (against a precomputed dummy hash when the email doesn't exist) so an unknown-email response takes the same time as a wrong-password response, closing a timing side-channel that could otherwise be used to enumerate registered emails.
